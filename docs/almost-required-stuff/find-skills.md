# find-skills

Discover and install agent skills from the open [agent skills](https://agentskills.io) ecosystem.

Use when asking "how do I do X", "find a skill for X", or "is there a skill that can...".
Searches [skills.sh](https://skills.sh/) and installs skills via `npx skills`.

## Install globally

```bash
npx skills add anthropics/skills@find-skills -g -y
```

Or copy the skill manually to `~/.agents/skills/find-skills/`.

## Verify

```bash
ls ~/.agents/skills/find-skills/SKILL.md
```
